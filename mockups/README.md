# Макеты интерфейса — Заметки (мокап **v2**, «Liquid Glass»)

Статические HTML/CSS-макеты, собранные по `SPEC.md`. **Гейт 2: макет на утверждение человеком.**
`DESIGN.md` появится только после утверждения этого макета.

Версия v2 — переработка по замечаниям гейта 2:
1. стиль переведён на **liquid glass** (живой фон + полупрозрачные панели с blur, светлые кромки, specular-блики);
2. в редакторе **включён toolbar** форматирования markdown;
3. из регистрации **убран чекбокс «условия»**.

Бэкенда, сохранений и реального markdown-рендера здесь нет: данные вымышленные, интерактив — минимальный
и нужен только чтобы показать состояния (переключение вида, фильтры, диалоги, табы редактора, кнопки форматирования).

## Как открыть

1. **Проще всего:** открыть `index.html` двойным щелчком в браузере (Chrome/Edge/Firefox) — оттуда ссылки на все экраны.
2. **Статический сервер** (рекомендуется, если в `responsive.html` не отрисовываются встроенные рамки при `file://`):

   ```bash
   cd mockups
   python -m http.server 8080       # затем http://localhost:8080/index.html
   # или: npx serve .              # затем http://localhost:3000/index.html
   ```

3. Ничего устанавливать не нужно: чистый HTML + CSS + ~200 строк демо-JS.

> Стиль рассчитан на современные браузеры с `backdrop-filter` (Chrome/Edge 76+, Firefox 103+, Safari 9+ с префиксом).
> Для остальных предусмотрен fallback — см. «Доступность и контраст на стекле».

## Что где «пощупать»

- **notes.html:** переключить «Плитки/Список» (работает клавиатурой: Tab → ←/→), ввести запрос в поиск,
  нажать чип тега, сочетать оба → увидеть «Ничего не найдено» + «Сбросить», нажать иконку корзины → диалог,
  ниже переключить состояния загрузки/ошибки/офлайна/пустого списка.
- **editor.html:** нажать кнопки toolbar (H1/H2/H3, жирный, курсив, списки, код, код-блок, цитата, ссылка) —
  markdown вставится в позицию курсора или обернёт выделение; изменение текста включает «есть несохранённые изменения»
  и счётчик символов; сузить окно < 1024 px → сплит превращается в табы.
- **note.html / login.html / register.html:** переключатели состояний над содержимым.
- **index.html:** витрина стекла — панели лежат на самом насыщенном фоне, рядом указаны замеры контраста.

## Дизайн-система: liquid glass

### Слои
1. **Живой фон** — фиксированный mesh-слой `body::before`: четыре цветных пятна (индиго / роза / cyan / violet)
   поверх светлого градиента, `filter: blur(46px)`, медленный дрейф `52s`. Размер пятен ограничен `min(vmax, px)`,
   поэтому на широких экранах фон не «раздувается» и не теряет композицию.
2. **Стекло** — панели: `backdrop-filter: blur(18px) saturate(175%)`, белая подложка с alpha, граница
   `1px rgba(255,255,255,.72)`, specular-кромка `inset 0 1px 0 rgba(255,255,255,.95)` и верхний блик-градиент через `::before`.
3. **Контраст** — под текстом всегда есть плотная подложка (см. ниже).

### Токены стекла (`styles.css`, раздел 1)

| Токен | Значение | Где применяется |
|---|---|---|
| `--glass-bg-hi` | `rgb(255 255 255 / .84)` | формы, диалоги, карточка авторизации |
| `--glass-bg` | `rgb(255 255 255 / .68)` | панели, карточки заметок, список |
| `--glass-bg-chrome` | `rgb(255 255 255 / .58)` | верхняя навигация, обычные кнопки |
| `--glass-bg-lo` | `rgb(255 255 255 / .42)` | треки переключателей, чипы, бейджи |
| `--glass-blur-sm` / `--glass-blur` / `--glass-blur-lg` | `10px` / `18px` / `28px` | кнопки и поля / панели / диалоги |
| `--glass-saturate` | `175%` | насыщенность под стеклом |
| `--glass-stroke` | `rgb(255 255 255 / .72)` | светлая 1px граница панелей |
| `--glass-edge` | `rgb(255 255 255 / .95)` | specular-кромка (`inset 0 1px 0`) |
| `--glass-sheen` | вертикальный градиент белого | блик по верхней части панели (`::before`) |
| `--glass-tint-indigo` | индиго→violet→cyan | цветная подложка брендовых блоков |
| `--glass-shadow` / `-hi` / `-lg` | мягкие тени `rgb(23 32 54 / .34…` | глубина слоёв |

Радиусы увеличены под стекло: `6 / 8 / 12 / 18 / 26 / pill`. Тень: `0 18px 36px -20px rgb(23 32 54 / .34)`.

### Примитивы
`.glass` (базовая панель), `.glass--hi` (плотная), `.glass--lo` (хром), `.glass--tint` (цветная подложка),
`.glass--flat` (без глубокой тени) — на них опираются панели, карточки, диалоги и авторизация.
Компоненты (`panel`, `note-item`, `empty`, `editor-pane`, `segmented`, `alert`, `chip`, `badge`, `md-toolbar`)
используют те же токены — единый вид на всех экранах.

## Доступность и контраст на стекле

Замеры сделаны для **худшего случая** — текст лежит на самой насыщенной зоне фона
(эффективный фон панели в зоне наложения пятен ≈ `#dfe0fc`):

| Текст | Токен | Контраст на стекле | Требование |
|---|---|---|---|
| Основной | `#0f172a` | ~13.8:1 (`.68`) · ~15.7:1 (`.84`) | AA/AAA (4.5 / 7) |
| Вторичный | `#3d4a5e` | ~6.9:1 (`.68`) · ~7.9:1 (`.84`) | AA/AAA |
| Приглушённый | `#4a5567` | ~5.8:1 (`.68`) · ~6.7:1 (`.84`) | AA |
| Граница поля ввода | `#8b93a3` | ~3.0:1 | AA (нетекстовые элементы, 1.4.11) |
| Кольцо фокуса | `#4338ca` | ~7:1 + светлый пояс 6px | видимый фокус |

Как это обеспечено:
- **плотность стекла под текстом** — панели с абзацами `alpha ≥ .68`, формы и диалоги `≥ .84`; текст не лежит на прозрачном стекле;
- **`--glass-bg-lo` (.42)** применяется только к «хрому» без длинных абзацев (треки, чипы, бейджи);
- **лёгкая тонировка сверху** (`::before`, белый градиент) дополнительно осветляет зону заголовков;
- **`prefers-contrast: more`** — плотность стекла и контраст границ автоматически увеличиваются;
- **`@supports not (backdrop-filter)`** — стекло становится почти непрозрачным (`alpha .94…​.96`), фон-подложка даёт контраст, вёрстка не ломается;
- **фокус**: 3px `#4338ca` + `outline-offset: 2px` + светлый пояс `box-shadow 0 0 0 6px rgba(255,255,255,.55)` — различим на стекле, на цветном пятне и на тёмной брендовой панели;
- **`prefers-reduced-motion`** — дрейф фона, shimmer скелетонов и hover-подъёмы карточек отключаются;
- **производительность на широких экранах**: hover-эффекты и анимации не перекрываются с blur, в режиме «список»
  стекло только на контейнере (иначе на каждой строке был бы свой `backdrop-filter`), `contain: paint` сознательно не используется,
  чтобы не обрезать кольца фокуса.

Плюс базовая доступность макета: видимый skip-link, семантические `h1` (один на страницу), `role="group"` +
`aria-pressed` для переключателя вида, `aria-invalid` / `aria-describedby` / `role="alert"` в формах,
`aria-label` у всех иконок-кнопок, `role="status"` для результатов поиска и статуса сохранения,
информация не передаётся только цветом (ошибки — иконка + текст, сила пароля — текстовая оценка).

## Панель форматирования markdown (включена в MVP)

`editor.html` → панель над полем ввода: **H1 / H2 / H3**, **жирный**, **курсив**, **маркированный список**,
**нумерованный список**, **код в строке**, **блок кода**, **цитата**, **ссылка**.
Кнопки вставляют markdown-синтаксис в позицию курсора или оборачивают выделение (в макете вставка демонстрационная,
в продукте — та же операция + отмена/повтор и горячие клавиши).

Доступность панели: `role="toolbar"` + `aria-label`, кнопки сгруппированы в `role="group"` с подписями
(«Заголовки», «Начертание», «Списки», «Блоки и ссылки»), у каждой кнопки `aria-label` и `title`,
разделители — `role="separator"`, подсказки горячих клавиш — `aria-keyshortcuts`, навигация — обычным Tab
(паддинги и кольцо фокуса не обрезаются), активное нажатие показывает состояние.

## Безопасность рендера в макете

Превью markdown в `editor.html` и `note.html` — **свёрстанная руками разметка-макет**, а не результат рендера.
В комментариях HTML отмечено, что в продукте markdown → HTML проходит санитайзер по allowlist (`<script>`, `on*`, `style`,
`iframe`, `javascript:` вырезаются). В `note.html` показан блок «как выглядит опасный ввод» — с ожидаемым результатом
(скрипт вырезан, элемент вне allowlist показывается как текст). Теги заметок везде рендерятся как текст.

## Демонстрационные данные (для ревью)

Список в `notes.html` намеренно включает граничные случаи из SPEC.md: очень длинный заголовок (E5),
заметка без заголовка (E3), длинный и юникодный теги (T3, T4), заметка без тегов (AC-35).

## Что нужно утвердить на гейте 2 (повторно)

**Стиль**
1. **Liquid glass как основа стиля:** живой mesh-фон (4 цветных пятна, медленный дрейф), стеклянные панели
   `blur 18px / saturate 175%`, светлые кромки и specular-блики. Вопрос: не слишком ли «нарядно» для рабочего
   инструмента заметок — при необходимости снижаем насыщенность пятен и глубину теней.
2. **Плотность стекла:** `.84` для форм/диалогов, `.68` для панелей и карточек, `.42` для «хрома».
   Это и есть механизм гарантии контраста — менять альфы вниз нельзя без перепроверки замеров.
3. **Палитра:** акцент индиго `#4f46e5` + градиент (индиго→violet) на primary-кнопках, семантические
   danger `#b42318` / success `#067647` / warning `#b54708`. **Тёмной темы по-прежнему нет** — если нужна,
   это отдельная задача (стекло в тёмной теме требует других альф и пересчёта контрастов).
4. **Радиусы увеличены** до 6/8/12/18/26/pill, тени мягче и глубже — это часть «стеклянного» языка.
5. **Анимация фона** (`52s` дрейф) — можно отключить совсем или оставить только при `prefers-reduced-motion: no-preference`.

**Список заметок**
6. **Дефолтный вид — плитки** (Q5a / AC-27), выбор сохраняется в localStorage.
7. **Структура карточки:** заголовок (clamp 2) → фрагмент (clamp 3) → теги → дата; действия «изменить»/«удалить» —
   иконками в углу, всегда видимы (не только на hover).
8. **Структура строки:** заголовок + фрагмент в одну строку → теги → дата; фрагмент скрывается при < 860 px.
9. **Один DOM на оба вида** (AC-26); в режиме списка стекло — только на контейнере (производительность).
10. **Два разных empty-state:** «заметок нет» (CTA) и «ничего не найдено» (сброс фильтров).
11. **Чипы тегов со счётчиком** заметок — если не нужны, убираем.

**Редактор**
12. **Toolbar включён в MVP** (решение гейта 2) в составе: H1–H3, жирный, курсив, списки, код, код-блок, цитата, ссылка.
    Вопрос: нужны ли горячие клавиши (`Ctrl/⌘+B/I/1…`) в MVP и как ведёт себя панель на мобильном
    (перенос в две строки вместо горизонтального скролла).
13. **Live-сплит 50/50** при ≥ 1025 px, ниже — табы «Редактор / Просмотр» (AC-30, NFR-23).
14. **Заголовок заметки — единственный `h1`**; markdown-заголовки внутри начинаются с `h2`.
15. **Явное сохранение** (не autosave): статус «есть несохранённые», диалог при уходе, ошибка сохранения без потери текста.

**Аутентификация**
16. **Вход по email**, саморегистрация, «Забыли пароль?» неактивен (вне MVP, Q-A8).
17. **Регистрация без чекбокса «условия»** (решение гейта 2). Обязательные поля: email, пароль, повтор пароля.
    Если согласие с обработкой данных нужно юридически — выносим ссылку в футер, а не обязательный чекбокс.
18. **Ошибки по контексту:** на регистрации — «email уже зарегистрирован» (AC-2), на входе — обобщённое
    «Неверные учётные данные» (AC-5, NFR-13). Rate-limit — предупреждение с таймером.

**Прочее**
19. **Загрузка — скелетоны** (стеклянный shimmer), ошибки с «Повторить», офлайн — предупреждение без потери ввода.
20. **Удаление — только модальный диалог** (стекло + размытый backdrop), фокус на «Отмена», корзины нет (Q10).
21. **Локаль — русский** (Q13); даты «13 окт, 09:20» в списках, «8 окт 2026, 20:15» в просмотре.
22. **Иконки — инлайн-SVG**, у всех иконок-кнопок есть `aria-label`.

## Осознанно не сделано в макете

- Тёмная тема, «+N» для тегов, bulk-действия, drag&drop сортировка, пагинация — не заявлены в SPEC.md
  или не выбраны как обязательные.
- Реальный markdown-рендер и санитайзер: показана только вёрстка ожидаемого результата.
- Сохранение выбора вида в localStorage: в макете описано в комментарии, но не реализовано (продуктовая логика).
- Настройка интенсивности blur/прозрачности пользователем (может быть предложена как настройка a11y).
