Макеты интерфейса: Заметки

Статические HTML/CSS-макеты по SPEC.md в стиле liquid glass: живой mesh-фон, полупрозрачные «стеклянные» панели с размытием, светлые кромки и specular-блики. Логики и бэкенда нет — интерактив нужен только чтобы показать состояния.

Это макет, а не продукт. Данные вымышленные, markdown-превью свёрстано руками (в продукте — рендер + санитайзер по allowlist, AC-45…AC-47). Ничего не сохраняется и не отправляется. Стиль переработан по замечаниям гейта 2 (v2: liquid glass, toolbar форматирования, регистрация без чекбокса «условия»).

Основа стиля: liquid glass

Три слоя, из которых собирается любой экран.

Слой 1 — живой фон

Фиксированный mesh-слой (body::before): четыре цветных «пятна» (индиго, роза, cyan, violet) поверх светлого градиента, blur(46px). Дрейф — 52s, отключается при prefers-reduced-motion. Размер пятен ограничен min(vmax, px) — на широких экранах не раздувается.

Слой 2 — стекло

Панели: backdrop-filter: blur(18px) saturate(175%), белая подложка alpha .42…​.84, граница 1px rgba(255,255,255,.72) и specular-кромка inset 0 1px 0 rgba(255,255,255,.95). Верхний блик — отдельный градиент (::before).

Слой 3 — контраст

Любая поверхность с текстом держит alpha ≥ .68, формы и диалоги — ≥ .84. Это гарантирует AA даже в самой насыщенной зоне фона (см. замеры ниже). При prefers-contrast: more плотность стекла растёт.

Fallback

Если backdrop-filter недоступен (@supports not), стекло становится почти непрозрачным: alpha .94…​.96, фон-подложка сохраняет контраст, вёрстка и структура не меняются.

Доступность стекла

  • Плотность подложки под текст: панели с абзацами — alpha ≥ .68, формы/диалоги/авторизация — ≥ .84. Ни один текстовый блок не лежит на «голом» фоне.
  • Замер контраста: в худшей зоне (насыщенное пятно под стеклом) основной текст ~13.8:1, вторичный ~6.9:1, приглушённый ~5.8:1 (для плотного стекла `.84` — 15.7 / 7.9 / 6.7) — все ≥ AA (4.5:1).
  • Границы полей ввода — #8b93a3 (~3:1): граница различима, не «исчезает» на стекле.
  • Фокус: 2–3px кольцо #4338ca (~7:1) + светлый «пояс» 6px — видно и на стекле, и на цветных пятнах, и на тёмной брендовой панели.
  • Преломление не мешает: размытие только под панелями; текст никогда не «плавает» на анимации.
  • Анимации: дрейф фона и shimmer скелетонов отключаются при prefers-reduced-motion: reduce.
  • prefers-contrast: more — плотность стекла и контраст границ увеличиваются автоматически.
  • Без backdrop-filter — @supports not даёт почти непрозрачную подложку: контраст гарантирован.
