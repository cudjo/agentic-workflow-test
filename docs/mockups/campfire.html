Сохранение только у костров (Q3), в бою запрещено — пункт отключён с причиной (не просто серый). Подтверждение сохранения ≤ 1 с (AC-05.1). Ошибка диска не перезаписывает старый файл (EC-14). Текст реплики печатается по символам; Enter/Пробел — показать целиком; при prefers-reduced-motion текст появляется сразу. Фракционный вариант ответа помечен тегом с последствием (US-06).
