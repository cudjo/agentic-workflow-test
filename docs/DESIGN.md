## 2. Принципы

1. **Мрак и тусклый свет.** Кадр тёмный; читаемость создают редкие тёплые источники (факелы, костёр, окна). Никакого неона и плавных свечений.
2. **Строгий пиксель.** Сетка 8 px, целочисленный масштаб, нет сглаживания, нет полупрозрачных плавных градиентов (тени/скримы — ступенями, свет — дизерингом Байера).
3. **Информация не только цветом.** Любое состояние дублируется формой, подписью или значком (US-07/NFR доступности).
4. **Герой читаем всегда** (AC-07.1): на героя действует холодная «подсветка силуэта», он не уходит в чёрный.
5. **HUD не перекрывает действие:** безопасная зона 8 px, значимое — по углам, центр свободен.

## 3. Экран и сетка

| Параметр | Значение | Примечание |
|---|---|---|
| Внутреннее разрешение | **480×270** | SPEC §7.2 (из двух вариантов выбран 480×270) |
| Масштаб | целочисленный ×1…×N; ×2 = 960×540, ×4 = 1920×1080, ×5.33 → ×5 + letterbox на 1440p | Не целое → ближайшее меньшее целое + рамка (letterbox) |
| Соотношение | 16:9; иначе letterbox (чёрные поля) | |
| Базовая сетка | **8 px**; тайл мира **16×16** | Допустимы шаги 2/4 для внутренних отступов |
| Safe-зона HUD | 8 px от края кадра | Для телевизоров/оверскана не нужна (ПК), но выдерживаем для единообразия |
| Минимальный читаемый размер | HUD читается на 1280×720 (×2 + поля → ×2.67 → ×2) | SPEC §7.2 |

**Godot [ПРЕДЛОЖЕНИЕ]:** `display/window/size/viewport_width=480`, `viewport_height=270`; `display/window/stretch/mode="viewport"`, `scale_mode="integer"`, `aspect="keep"`; `rendering/textures/canvas_textures/default_texture_filter=Nearest`; UI на отдельном `CanvasLayer`.
Опция «Масштаб интерфейса» (100/150/200%) в Godot реализуется как отдельная настройка размера шрифта/UI-контейнеров, а не как нецелый масштаб вьюпорта (см. §9).

### 4.2. Типографика

| Токен | Размер / строка | Применение |
|---|---|---|
| `font-body` | 8 / 12 px | Весь UI-текст, подписи, реплики |
| `font-h2` | 16 / 16 px | Названия пунктов меню, зона-баннер, «БОЛОТО» на загрузке |
| `font-h1` | 24 / 24 px | Верхняя строка названия игры |
| `font-title` | 32 / 32 px | «БАСТИОН», «ТЫ ПОГИБ» |

- Размеры **кратны 8** (пиксельная сетка шрифта). Межстрочный — 12 px для тела.
- **Шрифт в макетах:** `Press Start 2P` (моноширинный, кириллица, 8 px = 1 пиксель шрифта на пиксель экрана).
- ⚠️ **[ОТКРЫТО] Лицензия:** Press Start 2P — **SIL OFL**, а не CC0 (Q8: «ассеты только CC0»). Варианты: (а) нарисовать собственный растровый шрифт RU+EN (BMFont/`FontFile`) — рекомендуется; (б) найти CC0-шрифт с кириллицей; (в) получить разрешение человека использовать OFL (лицензия допускает использование в играх, но не CC0). Макет использует его как заглушку.
- Длина строк: ≤ 47 символов при ширине диалога 380 px (8 px/символ). RU обычно на 20–30% длиннее EN — проверять переполнение обеих локализаций (Q7).
- Регистр: заголовки панелей — ВЕРХНИЙ; пункты меню и реплики — обычный.

### 4.4. Слои (z-order)

1. Мир (параллакс 0.1× небо → 0.3× хребты → 0.5× силуэт замка → 1× основной → передний план).
2. Освещение (Light2D + дизеринг).
3. HUD (`CanvasLayer 10`).
4. Диалог/инвентарь/меню (`CanvasLayer 20`).
5. Тосты и подсказки (`CanvasLayer 30`).
6. Затемнения, экран смерти, загрузка (`CanvasLayer 40`).

| Компонент | Описание [МАКЕТ] | Godot-реализация [ПРЕДЛОЖЕНИЕ] |

### 6.5. Смерть (AC-05.2/05.3, EC-05)

- Появление через `T_death`: заголовок → панели → кнопки → предупреждение (ступенчатый fade).
- Первая смерть: «ОСТАЛОСЬ НА МЕСТЕ ГИБЕЛИ» — валюта, число предметов, превью первых 5, карта с меткой «Твои вещи» и костром.
- Повторная смерть до подбора: «УТРАЧЕНО НАВСЕГДА», метка меняется на череп, подпись «Вернуть уже нельзя».
- Фокус по умолчанию — «Возродиться у костра».

## 7. Состояния персонажа

Спрайт героя **16×24 px** (в макете 16×23 с мечом), хитбокс **10×20 px** (в `zone-village.html` включается «Разметка слоёв»). Лист: ≤ 16 цветов на спрайт (SPEC §6.1), 6–12 кадров на базовое действие (§6.3). ## 9. Доступность (a11y)

### 9.1. Зрение
- **Контраст** — см. §4.1 (текст 8 px ≥ 4.5:1: `bone`, `gold-3`, `stone-5`, `steel-3`, `blood-5`). `blood` (#7A2A24) и `stone` на тёмном — только декор.
- **Не только цвет:** HP — число; выносливость 0 — «НЕТ СИЛ» + «!»; репутация — знак ±; требования — «ЕСТЬ/НЕТ·ещё N»; ошибка — «!» + текст; блокировка — замок.
- **Масштаб интерфейса** 100 / 150 / 200% [ПРЕДЛОЖЕНИЕ, SPEC §7.4]: через увеличенные `font_size`/контейнеры (шаг по 8 px), не через нецелый масштаб вьюпорта. Минимальный размер текста — 8 px в 480×270 = 16 px на 1080p (читаемо на 1280×720, где ×2 даёт 16 px).
- **Режим «Читаемость силуэтов»** [SPEC §7.4]: у героя и врагов 1-пиксельный светлый контур (`bone` 60%), усиление rim-light героя; отключает виньетку.
- **Дальтонизм:** HP (красный) и выносливость (синий) различаются по форме (сегменты разной длины/высоты, иконки) и позиции; режим не требует замены палитры.

### 9.2. Моторика и ввод
- Полная навигация UI без мыши: стрелки/D-pad/левый стик, `Enter`/`A` (подтвердить), `Esc`/`B` (назад), `LB/RB` или `Tab` — вкладки.
- Единый порядок фокуса: слева направо, сверху вниз; возврат в меню запоминает предыдущий пункт.
- Видимый фокус обязателен (золотая каретка + рамка 1 px), толщина ≥ 2 px, контраст ≥ 3:1 (`gold` на `night-9` 6.1:1).
- Переназначение клавиш/кнопок (AC-01.3) — UI не нарисован, требует отдельного макета; подсказки на экране автоматически переключаются между клавиатурой, Xbox, PlayStation (EC-08).
- Буфер ввода 150 мс (AC-01.4) также применяется к меню-подтверждениям, чтобы двойное нажатие не пропускало экран.
- Мышь: цели ≥ 16×16 px экрана; hover = фокус.

### 9.3. Мигание и движение
- `prefers-reduced-motion`/настройка «Без мигания»: отключает мерцание факелов, мигание HP/каретки, вспышки урона и тряску; fade-in экрана смерти и печать текста — мгновенно. Не более 3 вспышек/сек в любом случае.
- Анимации ступенчатые, малоамплитудные; параллакс отключаем в режиме «Без мигания» (опционально).

### 9.4. Звук и субтитры
- «Субтитры звуков» (ключевые: босс рядом, удар, смена фазы) — тумблер в настройках [ПРЕДЛОЖЕНИЕ]. Смена трека за ≤ 2 с (AC-07.2) без критичных звуковых подсказок только на слух.

### 9.5. Семантика (в макетах — HTML/ARIA; в Godot — эквиваленты)
- Названия экранов — заголовки; меню — `role=menu/menuitem`; шкалы — `role=progressbar` с `aria-valuenow/valuetext`; тосты — `role=status` (информация) или `role=alert` (ошибка/«ТЫ ПОГИБ»); отключённые пункты — `aria-disabled` + описание причины (`aria-describedby`).
- В Godot — поля `accessibility_name/description` (4.5+) и экранный диктор для ключевых событий: смерть, сохранение, ошибка, смена фазы [ПРЕДЛОЖЕНИЕ].
- Язык интерфейса `lang=ru/en`; локализация через `TranslationServer` (Q7).

### 9.6. Чек-лист приёмки a11y для Tasker/QA
1. Любой экран проходится только клавиатурой и только геймпадом.
2. Фокус виден на каждом интерактивном элементе.
3. Весь 8-px-текст ≥ 4.5:1 на фактическом фоне (проверять поверх сцены; для текста на сцене использовать подложку-панель или тень `void` 1 px).
4. Нет состояния, различимого только цветом.
5. При включённом «Без мигания» нет вспышек > 3 Гц.
6. Тексты RU и EN помещаются во все панели при масштабе UI 100/150%.
7. Игра различима при яркости по умолчанию: герой отличим от фона (AC-07.1).
